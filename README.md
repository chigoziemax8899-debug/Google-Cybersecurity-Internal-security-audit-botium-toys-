**Portfolio Project** | Google Cybersecurity Professional Certificate (Coursera)  
**Course:** Play It Safe: Manage Security Risks

---

## Project Overview

This project simulates an internal IT security audit for Botium Toys, a fictional small U.S. toy company with growing online sales (including EU customers).  

The goal was to evaluate the company’s current security posture against industry best practices and compliance requirements, identify gaps, and provide actionable recommendations.

### Frameworks & Standards Used
- NIST Cybersecurity Framework (CSF)
- PCI DSS (Payment Card Industry Data Security Standard)
- GDPR (General Data Protection Regulation)
- SOC (System and Organization Controls)

---

## What I Did

1. Reviewed the audit scope, goals, and existing risk assessment
2. Analyzed current assets managed by the IT department
3. Evaluated existing security controls (administrative, technical, and physical)
4. Assessed compliance with PCI DSS, GDPR, and SOC best practices
5. Completed a full Controls and Compliance Checklist
6. Provided prioritized recommendations to improve security posture and reduce risk

---

## Key Findings

**Strengths**
- Firewall is properly configured
- Antivirus software is installed and monitored
- Physical security (locks, CCTV, fire detection) is adequate
- GDPR breach notification plan exists (72-hour rule)
- Privacy policies and data integrity controls are in place

**Critical Gaps**
- No least privilege or separation of duties
- No encryption for credit card / customer PII data
- No disaster recovery plan or backups of critical data
- No Intrusion Detection System (IDS)
- Weak password policy with no centralized enforcement
- All employees have broad access to sensitive data

**Risk Score:** 8/10 (High) – mainly due to missing controls and compliance gaps

## Recommendations (Summary)

1. Implement least privilege access and separation of duties
2. Encrypt all credit card and customer personal data (at rest and in transit)
3. Establish regular backups and a formal disaster recovery plan
4. Deploy an Intrusion Detection System (IDS)
5. Strengthen password policy and implement a centralized password management system
6. Complete a full asset inventory and data classification exercise
